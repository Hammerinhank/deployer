1. Connexion GitHub

Analyse tous les fichiers .html et .py de tous tes dépôts GitHub, sur leurs commits récents (jusqu'à 30 par fichier), à la recherche de tokens ou secrets câblés en dur. Peut prendre plusieurs minutes et consommer beaucoup d'appels API selon le nombre de dépôts. Des faux positifs sont possibles.

2. Gestion des Applications Cibles

Coche une application ci-dessous pour activer, à l'étape 3, le bouton de mise à jour de ses fichiers autres que le HTML — le bouton n'apparaît que lorsque cette application est aussi celle sélectionnée dans le menu déroulant de l'étape 3.

➕ Créer un nouveau dépôt

Crée un dépôt tout neuf, y ajoute une page de départ, active GitHub Pages et l'enregistre automatiquement comme cible ci-dessus.

5. Synchronisation des cibles

Ta liste de cibles peut être sauvegardée en double : dans ce navigateur et dans un fichier JSON d'un de tes dépôts GitHub. Les deux copies sont maintenues cohérentes (la plus récente fait foi), ce qui te permet de retrouver la même liste sur ton iMac et ton iPhone.

🔒 Ton token n'est jamais synchronisé : il reste uniquement dans ce navigateur. Seule la liste des cibles (noms d'affichage, noms de dépôts et cases cochées à l'étape 2) part sur GitHub. Tu peux d'ailleurs utiliser un dépôt privé pour cette sauvegarde.

📁 Mise à jour des autres fichiers

Pour l'application sélectionnée à l'étape 3 (et cochée à l'étape 2) : liste des fichiers du dépôt autres que le fichier HTML. Colle le nouveau contenu ou glisse-dépose un fichier sur une zone, ajoute un commentaire de version (obligatoire, 3 mots minimum), puis clique sur « Mettre à jour sur GitHub » pour ce fichier précis. Double-clic (ou double-tap) sur une zone pour la vider. Pour les fichiers texte, le bouton « Edit » ouvre en plein écran la dernière version du fichier sur GitHub, plus confortable à éditer sur iPhone. Reste appuyé plus de 5 secondes sur « Charger l'historique » pour charger tout l'historique en continu (le bouton devient rouge) ; un simple appui dessus pendant qu'il est rouge arrête le chargement.

✏️ Édition

À l'ouverture, cette zone se charge avec la dernière version du fichier telle qu'elle est actuellement sur GitHub. Modifie-la à l'aise en plein écran. Rien n'est envoyé sur GitHub depuis cette page : au retour, tu choisiras si ce texte remplace le contenu de la zone de la page précédente. Tant qu'aucun commit n'est fait, ce texte n'est pas conservé si tu fermes l'appli.
